## 📖 About

Responsive landing page for a fictional restaurant, featuring pasta, pizza and dessert menus as well as an illustrative reservation form.

## ✨ Features

- Menu presentation
- Illustrative reservation form
- Responsive layout

## 🚀 Run locally

```bash
git clone https://github.com/Felipe-Amorim-Dev/la-tavola-italiana.git
cd la-tavola-italiana
```

Open `index.html` in a browser.
